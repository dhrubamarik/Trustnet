How it works
01
Ingest
Review arrives with text, author, merchant, IP, device and payment token. Text and ratings are real Kaggle data; entity fields are synthesized because platforms never release them.
02
Feature pipeline
Dual-space TF-IDF (word + char n-grams), entity-sharing counts, temporal velocity. 19 numeric features extracted per review.
03
Weak supervision
Eight weighted labeling functions vote on an anomaly score. Ring separation is 9.6× against baseline reviewers.
04
Graph linking
Union-find components join entities sharing hardware, payment, IP or copy. Edges below weight 4.0 are dropped — at least two signal types must agree.
05
Case rollup
Scattered bot accounts collapse into one urgent case with a named-signal evidence trail and a human-readable triage action.
